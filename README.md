# PUP Biñan Campus Level 1 Accreditation Website

This project is the official web-based platform being developed in support of the **Level 1 Accreditation of the Polytechnic University of the Philippines (PUP) Biñan Campus**.

The website will provide an organized and accessible space for presenting accreditation-related information, documents, evidence, and other relevant campus resources. It is intended to help the accreditation team, faculty members, staff, student developers, and evaluators find the information they need through a clear and consistent interface.

## Project Purpose

The website aims to:

- Support the Level 1 accreditation activities of PUP Biñan Campus.
- Present accreditation information and supporting evidence in an organized manner.
- Make relevant resources easier for authorized stakeholders and evaluators to access.
- Provide a maintainable platform that future student developers can understand and improve.
- Represent the campus through a professional, responsive, and user-friendly digital experience.

## Current Status

The project is currently under development. A temporary **Coming Soon** page is displayed while the content, features, and accreditation materials are being prepared.

## Technology

The website is built with:

- TypeScript
- Vite
- Tailwind CSS
